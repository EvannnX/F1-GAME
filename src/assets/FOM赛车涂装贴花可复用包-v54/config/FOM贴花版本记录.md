### 左右参数自动同步（预览 v37）

GUI 的方向区域增加了“同步镜像到左侧/右侧”按钮。选择任意一组右侧贴花并调整完成后，点击按钮会：

- 同步整体、宽度、高度、Y、Z、旋转 X、翻转和正反状态。
- 将 X 变为相反数。
- 将旋转 Y 和旋转 Z 变为相反数。
- 立即重建对应侧的曲面吸附贴花。

主 SVG、DeltaX 以及全部赞助商 Logo 均支持此操作；尾翼贴花没有左右配对，因此按钮会自动禁用。

## 分区涂装方案（预览 v54）

沿用原车身同表面分区着色逻辑，现提供 8 套可实时切换的方案：

| 方案 | 辅助颜色 | 布局 |
|---|---|---|
| 纯色 | 无 | 关闭额外分区 |
| 红白经典 | 白色、深黑 | 红色主体 + 白色鼻锥肩部 + 黑色侧箱下部 |
| 银黑青线 | 银灰、青色 | 黑色主体 + 银灰结构面 + 连续青色边界线 |
| 橙黑切面 | 深黑、青绿色 | 橙色主体 + 黑色侧箱和鼻锥主轴 + 青绿色细边 |
| 蓝白箭锋 | 白色、深蓝黑 | 蓝色主体 + 白色鼻锥外肩 + 深色上侧箭面 |
| 紫金翼面 | 金色、深黑 | NYU 紫主体 + 金色侧面扫线和鼻锥导轨 + 深色侧箱下部 |
| 绿黑渐切 | 深黑、荧光绿 | 绿色主体 + 黑色斜切侧箱 + 荧光绿结构边 |
| 银白红脊 | 红色、深黑 | 银白主体 + 红色侧面中段和鼻锥主脊 + 黑色侧箱下部 |

侧面分区沿完整侧箱体块延伸，鼻锥分区沿主轴和左右肩线延伸。Logo 可以处在完整色块之上，但任何分色边界都不会穿过 Logo。

从 v53 开始，分区不再使用任何额外贴花网格；v54 在同一逻辑上增加四套不同主色与不同结构分区。所有颜色直接在原车身材质的同一表面着色，因此不会隆起、穿模或出现不规则贴合；赞助商 Logo 保持独立上层显示，不会被分区遮挡。原始纹理细节通过材质亮度保留。

完整机器可读配置保存在 `FOM分区涂装配置.json`。
