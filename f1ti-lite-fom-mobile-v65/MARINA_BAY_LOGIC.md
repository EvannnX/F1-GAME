# 滨海湾赛道逻辑基线（build 188）

## 数据来源

- 地图：`assets/marina-bay-street-circuit.glb`
- 主赛道路面：`Object_19` 的材质 `11001Mtl_14`（GLB material index 15）
- 地图缩放：`0.5`
- 路线提取工具：`tools/extract-marina-bay-route.py`
- 正式游戏数据：`marina-bay-baseline-data.js`

## 赛道逻辑

- 从主赛道路面 mesh 生成唯一闭合中心线，自动剪除开放的维修区和辅路分支。
- 闭环共 834 个点，正式游戏内点间距约 3 米，最新保存路线总长度约 2507.99 米。
- 导览线、小地图、AI 对手和圈进度共用同一条路线，避免不同系统各自重新计算。
- 正式加载时仅向下投射到主赛道路面；窄材质接缝只允许在路线法线方向最多 2.1 米内寻找最近主赛道点。
- GLB 加载后会先以整个模型的 X/Z 中心重定位，路线提取现在复制同一变换：原始模型中心为 `X 96.878261 / Z 199.727820`。这修复了旧路线相对发车格整体偏移的根本问题。

## 碰撞逻辑

- 只有 `11001Mtl_14` 被认定为滨海湾主赛道。
- 维修区、辅路、路外铺装和景观表面不会被判定为正常赛道路面。
- 使用 GLB 实际路面高度和法线贴地；赛道边缘继续使用现有车辆边界碰撞与减速/反弹逻辑。
- 滨海湾绕过二维高度网格，直接按当前位置和上一帧高度采样 GLB，避免立交或多层结构选错层。

## 起终点

- 当前发车位置：`X -348.580 / Y 由路面采样 / Z 49.880`
- 整条闭环已按正式游戏中的 GLB 重定位逻辑重新计算，首点是距离玩家发车格最近的主赛道中心点 `X -344.511 / Z 49.807`，距离发车格约 `4.07 m`。
- 朝向：`7.3°`，路线首段切线为约 `7.43°`。
- 必须先完成至少路线总长 80% 的有效行驶，再次经过起终点才会结算，避免刚发车即误判。

## 0.4 赛车尺寸适配

- 滨海湾沿用亚斯码头的 0.4 尺寸规则：HUD 显示速度保持原值，玩家与 AI 在场景中的实际位移速度乘以 `0.4`。
- 第三人称镜头的后距、高度、横向偏移与近裁剪面按 `0.4 / 0.7` 缩放，使赛车在画面中的大小与其他已适配赛道一致。
- 不修改用户保存的发车 X/Z、朝向或各赛车尺寸。

## 导览线拖动 GUI

- 地址参数：`?track=marina-bay&routeDragGui=1`
- 操作：普通左键旋转、右键平移、滚轮缩放；按住 Shift 在导览线附近拖动。
- “平滑当前路段”只平滑选中点附近；松开、平滑和“完成并进入游戏”都会保存。
- 存储键：`f1ti_marina_bay_route_xz_override_v1`，与亚斯码头和加泰罗尼亚完全隔离。
- 正式游戏启动时优先读取该路线；导览线、AI、小地图与起终点均使用同一份保存数据。

## 赛车碰撞与导览线尺寸（build 182）

- 当前 GLB 正式游戏循环已加入玩家与 AI 赛车的实体碰撞，不再穿过前车模型。
- 碰撞体按 0.4 赛车尺寸使用方向长方形范围，并检查高度差；立交桥上下层车辆不会互相碰撞。
- 追尾会把玩家推回前车后方并明显降低双方速度；侧碰会横向分离、轻微改变玩家朝向并减速。
- 滨海湾导览线宽度缩小为 build 181 的 0.5 倍；长度、点位、路线密度和保存数据均不变。

## 轮胎贴地（build 183）

- 物理中心固定在路面上方 `0.09 m`，通用可视模型摆放已下移 `0.06 m`；本次精确补齐剩余 `0.03 m` 可见空隙。
- 玩家车型在模型加载和尺寸归一化后读取真实轮胎最低点，并沿当前道路法线下移到轮胎触地。
- 滨海湾全部 AI 车型使用同样的 `0.09 m + 轮胎最低点` 补偿，不再只处理 Ferrari 和 Red Bull。
- 接触阴影同步补偿轮胎偏移，保持在路面上方，避免沉入路面或悬在车底。

## 贴地过度修正（build 184）

- build 183 依赖轮胎/轮毂 mesh 名称识别最低点；部分车型只命中轮毂，会误把轮毂压到路面并使外胎陷地。
- 滨海湾现在不再使用车型名称推测的轮胎偏移，只补偿经过确认的 `0.03 m` 空隙，以模型归一化后的真实最低几何面为接触面。
- 玩家和全部 AI 使用同一补偿，仍沿赛道法线摆放；发车位置、朝向、车辆尺寸与导览线不变。

## 墙面与环境碰撞（build 185）

- 只排除主赛道路面材质 `11001Mtl_14`；其余 GLB 网格仅在三角面接近垂直、具有有效高度且与赛车当前高度相交时才进入碰撞器。
- 墙面、护栏、围栏、隔离墩和立柱会阻挡赛车；地面、桥面、高空广告和隐藏物体不会被误判为空气墙。
- 滨海湾在车辆仍位于赛道材质上时也会逐帧扫描车头移动段，修复“车头已经穿墙、车辆中心仍在道路上”导致的穿模。
- 碰撞体按 0.4 赛车尺寸缩放；正面撞击会阻止穿透并减速，擦墙允许沿墙滑动但持续降速。
- 未修改发车位置、朝向、车辆尺寸、贴地、导览线、小地图和 AI 路线。

## 空气墙修复（build 186）

- build 185 将全部非赛道编号材质作为候选，错误包含了建筑外墙、广告牌、透明装饰面和高架景观，造成路上空气墙。
- 现在只保留经过贴图与网格核对的护栏/混凝土墙材质：`11001Mtl_71`、`11001Mtl_72`、`11001Mtl_73`、`11001Mtl_79`、`11001Mtl_80`。
- 碰撞半径与车头前探距离进一步按 0.4 赛车尺寸收紧，赛车接触可见墙面后才响应，不会提前被无形范围挡住。
- 透明面、广告牌、建筑装饰、桥梁外观和其他非墙体网格不再参与碰撞。

## 关闭赛车间碰撞（build 187）

- 滨海湾玩家赛车与所有 AI 赛车之间不再执行实体碰撞，可以互相穿过。
- 墙面、护栏和混凝土墙碰撞继续保留。
- 其他赛道原有的赛车碰撞逻辑不受影响。
- 导览线拖动 GUI 继续使用 `f1ti_marina_bay_route_xz_override_v1`，保存后正式游戏读取同一份路线。

## 最新路线固化（build 188）

- 发车格、车辆尺寸、方向、墙面碰撞与赛车间无碰撞设定保持不变。
